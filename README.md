# Portfolio — Valentin Hassenforder

Product Engineer · UX/UI & Next.js. Site bilingue FR/EN.

## Démarrer

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000 (redirige vers `/fr` ou `/en`).

## Scripts

| Commande | Rôle |
|---|---|
| `npm run dev` | Serveur de développement |
| `npm run lint` | ESLint |
| `npm run build` | Build de production |

## Méthode

Le repo suit la méthode décrite dans `CLAUDE.md` : contexte versionné dans `contexte/`,
journal dans `docs/decisions.md`, et rituel pré-push `/ship` avant chaque push.
