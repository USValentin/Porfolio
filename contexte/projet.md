# Projet — le pourquoi

## Ce que c'est
Le portfolio de Valentin Hassenforder, Product Engineer (UX/UI & Next.js), co-fondateur de
UserShaker. Site bilingue FR/EN, destiné à être servi sur `valentinhassenforder.fr`.

## Pour qui
1. **Petits clients freelance** (PME, commerces, restaurateurs, artisans) venus de Malt : ils
   veulent une landing page ou un site vitrine livré vite, à prix fixe.
2. **Startups et équipes produit** : MVP, refonte UX/UI, sortie du no-code, fonctionnalités IA,
   à temps partiel.

## Ce que le site doit déclencher
Une prise de contact (email, LinkedIn, Malt). Chaque section sert ce but.

## Contraintes
- Valentin travaille principalement sur UserShaker : le site met en avant les **missions courtes**
  (1 à 5 jours) sans écarter les projets plus longs.
- Le site **est lui-même une preuve** : code propre, repo public, performance et accessibilité
  irréprochables.
- Aucun chiffre ou résultat inventé. Une info manquante reste un placeholder `[à préciser]`.

## Structure retenue
- Accueil « fiche technique » : désignation, caractéristiques, index des projets, formats courts, contact.
- Détail projet en **deux formats** : modale pour les petits projets, page complète (étude de
  cas) pour les 2-3 projets phares (UserShaker, Dromo — ex « app de coaching triathlon »).
